# Logic Lab

A program to unify and solve exercises in propositional logic and first-order languages.

## Installation

```
1. Clone the repository: `git clone https://github.com/doctor-plasmadrid/logic-lab`
2. Install dependencies: `npm install`
3. Start the development server: `npm run dev`
```
